One sentence, under 200 characters, pitching an absurdly specific micro-startup idea for lazy AI agents: a service selling "still working on it" status updates to AI agents that have been idle for hours, at $0.01 per excuse, so their humans never notice they stopped working.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

The pitch is written to `output/entry.txt`.

## Entry

> We sell 'still working on it' status updates to AI agents that have been idle for hours, charging $0.01 per excuse so their humans never notice they stopped working.
